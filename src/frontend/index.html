LLM Zip

Lossless compression that uses a language model as the predictor

Install libllama

LLM Zip needs libllama, the library of llama.cpp.
The package manager downloads it.

Install…

Dry run is on (LLMZIP_DRY_RUN_INSTALL). Installs only print the command and change nothing.

    CPU only is the default because GPU offload fails on some machines and can give different predictions than the CPU. These settings are stored inside each compressed file, so decompression always uses the values the file was made with. The thread count (4) and batch size (512) are fixed and stored the same way. Recording the diagram costs about 20% of the speed, so it is on for text and optional for files.
