LLM Zip

Lossless compression that uses a language model as the predictor

Setup needed

LLM Zip needs the llama-zip command line tool. Install it once with Python:

pipx install git+https://github.com/alexbuz/llama-zip.git

Model

No model selected

Any llama.cpp-compatible model works. A small base model compresses fast. A larger one compresses better. Decompression needs the exact same model file.

Advanced

CPU only is the default because GPU offload fails on some machines and can give different predictions than the CPU. These settings are stored inside each compressed file, so decompression always uses the values the file was made with.

Drop files here
Any file compresses to .llmz. An .llmz file decompresses.
